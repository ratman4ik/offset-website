# OFFSET® — Phase 1

Production-oriented portfolio foundation for OFFSET®, an independent digital design and web development studio based in Ireland.

## Run locally

```bash
npm install
npm run dev
```

Quality checks:

```bash
npm run lint
npm run typecheck
npm run build
```

## Content

- Project and team records live in `data/site.ts`.
- The NOIR AUTO URL is intentionally `null` until a real destination is supplied.
- Contact information is intentionally shown as pending; no address or social account has been invented.
- The crew passes are draggable 2D studies. Advanced physics and 3D lanyards remain Phase 2 work.

## Design system

The UI/UX Pro Max research output is persisted in `design-system/offset/MASTER.md`. The implemented direction uses the supplied OFFSET colour system, local Archivo and Space Grotesk variable fonts, editorial grids, and reduced-motion fallbacks.
